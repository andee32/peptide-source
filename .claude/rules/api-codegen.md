# API is spec-driven — do not hand-edit generated code

The Zod schemas in `lib/api-zod/src/generated/**` and the React Query hooks in
`lib/api-client-react/src/generated/**` are **generated by Orval** from
`lib/api-spec/openapi.yaml`. Never hand-edit the generated files — changes are lost
on the next codegen.

To change the API:
1. Edit `lib/api-spec/openapi.yaml` (the source of truth).
2. Run `pnpm --filter @atlab/api-spec run codegen`.
3. If a consuming package (e.g. `@atlab/api-server`, `@atlab/storefront`) starts
   depending on a newly generated type, ensure its `tsconfig.json` `references`
   include the source package, or the root `tsc --build` breaks.

When adding B2B/compliance endpoints (accounts, price tiers, attestations, ACH),
add their schemas to `openapi.yaml` first, then regenerate.
